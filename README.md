# Site shots

Pictures of this site's first screen. This first set was taken by hand from the live site (https://sticks-web.vercel.app) at the sizes .github/workflows/site-shots.yml uses; later sets are written by that workflow on main after its health gate passes.
manifest.json names the newest set; shots/<commit>/ holds each set; latest/ is a copy of the newest set. Do not edit by hand.
